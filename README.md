# Design and validation of a Smart Home Security System.

In this project you will design and validate a Smart home security system which includes components like motion sensors, cameras, alarm, and a central control unit.

You will document the requirements, evaluate design tradeoffs, create system models using SysML, and develop a verification and validation plan to ensure the system meets user needs.

The main goal of the project is to submit 5 items:

1. System Requirements Speficification (SysRS) document - For this document you MUST follow the following [template](starter/System%20Requirements%20Specification%20Template.md). You can use google docs/MS Word to create your document and then submit as PDF. Inside the starter template you will see each part of the document explaining what it should contain.

2. Architecture diagrams (and others) - Use [draw.io](https://app.diagrams.net) to create the Architecture diagram of the system and upload the exported .drawio file

3. SysML block diagram - Use [plantUML editor](https://plantuml.com/plantuml) to create the diagram. You can submit the code in a .txt or .uml file (and the JPEG image if you want).

4. Decision Matrix (as .xls file) - You must use the following [template](https://docs.google.com/spreadsheets/d/1psfU-u3K2RuDNjDbheKFOFB0bU3SXjCIYUNGXc6tBwo/edit?usp=sharing) to build the decision matrix. The project asks for one decision matrix per item (sensors, controllers, server/manager) so you can submit a single file with multiple tabs for each one or one file for each item.

5. Testomat test cases - Here you MUST use [testomat](https://app.testomat.io) to create the test cases and export them as spreadsheet using their export option. Follow the instructions in the project lesson on how to export the test cases.
